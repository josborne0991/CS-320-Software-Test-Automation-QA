Portfolio artifacts from CS 320 Software Test Automation and QA at SNHU

## Reflection

### How can I ensure that my code, program, or software is functional and secure?

I can ensure that my code is functional and secure by testing it throughout the development process instead of waiting until the end. In this course, I learned how useful unit testing is for checking requirements and catching errors before they become bigger problems. I also learned the importance of testing both valid and invalid inputs so that the program behaves the way it is supposed to.

### How do I interpret user needs and incorporate them into a program?

I interpret user needs by first looking closely at the requirements and determining exactly what the program needs to accomplish. From there, I can break those requirements into smaller pieces and make sure each one is represented in the code. Testing is also important because it allows me to verify that the final program actually meets those requirements.

### How do I approach designing software?

I approach software design by breaking a larger problem into smaller, manageable parts. I like to work through one requirement at a time and test my work as I go. This course showed me that planning, testing, and making improvements throughout development can make the final program more reliable and easier to maintain.
